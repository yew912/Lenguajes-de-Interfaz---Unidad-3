# Repositorio de Prácticas - Unidad 3
Lenguajes de Interfaz | Programación en Ensamblador con Irvine32

## Registro de Prácticas y Ejercicios

* Práctica Inicial (Procedimientos): Utilización de subrutinas con la estructura PROC/ENDP, despliegue de mensajes en consola y extracción de direcciones de memoria mediante WriteHex para localizar las etiquetas de salto.
* Práctica de Cadenas (Buffers): Implementación de lectura de entradas por teclado almacenadas en un búfer delimitado, cálculo dinámico de longitud y retransmisión de caracteres leídos.
* Práctica de Condicionales (Comparaciones): Evaluación lógica de flujos y bifurcaciones mediante la instrucción de comparación (cmp) utilizando el registro ECX para validar estados de entrada.
* Práctica de Manejo de Pila: Control manual del stack con instrucciones push y pop para el paso de parámetros hacia subrutinas aritméticas, asegurando la integridad y restauración de registros críticos como EBX.
* Práctica de Macros: Automatización de tareas repetitivas mediante la declaración de bloques MACRO para imprimir textos y saltos de línea con menor cantidad de líneas de código.
